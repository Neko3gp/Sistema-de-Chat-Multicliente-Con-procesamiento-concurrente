- `BACKEND_TODO.md`: estado actual y pendientes reales del backend.
- `cambios_en_conexion.md`: historial resumido de decisiones de integración.
- `REPORTE_PARA_COMPANERO.md`: guía breve para coordinar pruebas entre ramas.

Los documentos de evidencia no deben mezclarse con instrucciones de ejecución:
los primeros explican qué se midió; el README explica cómo usar el sistema.
